这是 ==Hamu 渲染器==, 经过慎重考虑后, 认为项目应该首先专注于图形学本身, 因此暂时决定先使用 `OpenGL` 进行开发 PBR 渲染器, 以便更快地实现核心功能. `Vulkan` 的支持将会在后续阶段引入, 以满足对性能和现代图形 API 的需求. 此外, `软光栅渲染`的选项也将会在未来的版本中考虑, 以提供更多的渲染选择和性能对比.
