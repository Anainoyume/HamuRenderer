## 阶段三：序列化闭环与场景管理 (6.8 - 6.14)

- [ ] 周一：编写 SceneSerializer 类骨架。
- [ ] 周二：实现序列化（Save）：遍历 Scene 中的 Entity -> 通过 EnTT 拿到 Component -> 查询 TypeRegistry 拿到反射信息 -> 将数据写入 nlohmann/json。
- [ ] 周三：完成序列化逻辑并保存为 .scene 文本文件。
- [ ] 周四：实现反序列化（Load）：读取 JSON -> 解析出 Component 名字 -> 通过 TypeRegistry 创建对应 Component -> 将 JSON 值写回内存。

- [ ] **6.13 - 6.14 (周末) | 相机系统与 Uniform Buffer**
