1. 什么是 **GLFWmonitor**
它就是对应电脑硬件显示器的一个抽象，如果说你是笔记本并且没有外接显示器，那 `glfwGetMonitors` 就一定只返回一个 Monitor，还有一个 API 是 `glfwGetPrimaryMonitor` 永远只返回主显示器。确实存在虚拟显示器这种东西，但一般情况我们不考虑，只考虑和硬件显示器一一对应的一个标识指针即可。

2. 什么是分辨率，什么是 DPI
把像素当成一个实际的小方格，分辨率就是 **width × height**，表示总共多少个小方格。dpi 就是每英寸点数，这里的点对应我们的像素。那么就是说一个实际的物理尺寸里总共有多少个像素。
然后还涉及到 `dpi scale` 这个东西，这个就是 `DPI 缩放`，这里要和 **硬件dpi** 区分开，硬件的 dpi 就是固定不变，我一英寸就是只能画这么多像素，物理上定死了。
但是如果我改 `dpi scale`，加入改成了 `150%`，那么假设原本 1英寸画1像素 (实际上不可能，这里只是举例子)，现在变成了我 1英寸要花 1.5 像素。可我屏幕大小已经固定了就这么大，所以就得用更多的像素画原本的这个东西，所以 UI 就会显得更大。
